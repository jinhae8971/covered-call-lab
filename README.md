# 커버드콜 ETF 리서치 랩

미국·한국 상장 커버드콜 ETF 49종을 **원지수 대비 초과수익 관점**으로 비교하는 자동 갱신 대시보드입니다.
투자 목표는 **총수익률 우선**으로 설정되어 있으며, 분배율은 선택 기준이 아니라 결과 지표로 다룹니다.

## 빠른 사용법

```bash
cd covered-call-lab
python build.py            # 전체 갱신 (약 2분, 49종목 API 호출)
python build.py --cache    # 원시 데이터 재사용, 지표·화면만 재계산 (수초)
python build.py --only-us  # 미국만
python build.py --only-kr  # 한국만
```

`dashboard.html`을 더블클릭하면 바로 열립니다. 데이터가 파일 안에 embed 되므로 서버가 필요 없고, `file://` 로도 정상 동작합니다.

## 3계층 구조

| 계층 | 파일 | 역할 | 갱신 주체 |
|---|---|---|---|
| 메타데이터 | `universe.json` | 종목 목록·세대 분류·오버라이트 방식·벤치마크 매핑 | 사람이 손으로 관리 |
| 데이터 | `build.py` → `data/` | 가격·분배금 수집, 지표 계산, 벤치마크 대비 평가, 점수화 | 스크립트 자동 |
| 화면 | `template.html` → `dashboard.html` | 표·차트·인사이트 렌더링 | 스크립트 자동 |

신규 ETF를 추가하려면 `universe.json`의 `us` 또는 `kr` 배열에 한 줄 넣고 `bm`(벤치마크 ID)을 지정한 뒤 `python build.py` 를 다시 돌리면 됩니다. 나머지는 전부 자동입니다.

### 산출물

- `data/raw_cache.json` — API 원시 응답 캐시 (`--cache` 로 재사용)
- `data/metrics.json` — 계산된 전 종목 지표 (다른 도구에서 그대로 소비 가능)
- `dashboard.html` — 단일 파일 대시보드

## 내 포트폴리오

대시보드 상단의 **내 포트폴리오** 카드에서 보유 종목·수량·평균단가를 입력하면 아래가 자동으로 계산됩니다. 커버드콜뿐 아니라 **SPY·VOO·QQQ·QQQM·DIA·IWM·VTI·SCHD**, 국내 상장 **KODEX 200·KODEX 코스닥150·KODEX/TIGER 미국S&P500·미국나스닥100·미국배당다우존스**도 담을 수 있어, 지수 코어 + 커버드콜 새틀라이트 구성을 한 화면에서 평가할 수 있습니다. 종목 선택 드롭다운은 «미국 대표 지수 / 국내 상장 지수 / 미국 커버드콜 / 국내 커버드콜» 네 그룹으로 나뉘어 있고, 「＋ 지수 추가」 버튼은 지수만 골라 넣습니다.

- **평가손익과 총수익** — 종목별/전체 평가금액, 매입 대비 손익, 수익률. 미국 상장분은 최신 USD/KRW로 원화 환산합니다. 평균단가는 각 종목의 거래 통화(미국 $, 한국 ₩)로 입력합니다.
- **예상 배당금 캘린더** — 최근 12개월 실제 분배 실적(TTM)을 기준선으로 삼아 종목별 지급 월 패턴에 맞춰 향후 12개월을 월별로 배분하고, 세전·세후를 함께 보여줍니다.
- **보유 종목 총수익 추이** — 보유 종목의 총수익 지수를 한 화면에 겹쳐 보고, 현재 비중으로 합성한 포트폴리오 곡선을 흰 선으로 표시합니다.
- **목표 비중과 리밸런싱** — 종목별 목표 비중을 넣으면 현재 비중과의 괴리, 맞추기 위한 매수/매도 금액을 계산합니다.
- **계좌 유형별 세후** — 일반계좌·연금계좌·ISA를 선택하면 각 계좌의 과세 방식을 적용합니다. 연금·ISA를 선택한 상태에서 미국 직상장 종목이 있으면 편입 불가 경고를 표시합니다.

> **보유 내역은 브라우저(localStorage)에만 저장되며 어떤 서버로도 전송되지 않습니다.** 레포가 public 이므로 보유 종목과 금액이 커밋되면 그대로 공개됩니다. 백업이나 다른 기기 이동은 **JSON 내보내기/불러오기**를 쓰세요. 내보낸 파일은 `.gitignore` 에 `portfolio*.json` 으로 등록해 두었습니다.

### 계산의 한계

분배금 추정은 예측이 아니라 **TTM 실적을 그대로 향후 12개월에 투영한 기준선**입니다. 커버드콜 분배금은 옵션 프리미엄에 연동돼 변동성이 높을수록 늘고 잔잔한 장에서는 줄어듭니다. 국내 ETF는 네이버가 회차별 분배 이력을 제공하지 않아 지급 월에 균등 배분한 근사치이며 회차별 편차는 반영되지 않습니다. 추이 차트의 포트폴리오 곡선은 과거 비중이 현재와 같았다고 가정하므로 실제 매매 이력과는 다르고, 환율은 현재값으로 고정했습니다. 평가익 과세는 '지금 전량 매도' 가정의 참고치이며 실제 세액은 보유기간·다른 소득·공제에 따라 달라집니다.

## 데이터 출처와 정확도

**미국** — Yahoo Finance chart API. `adjclose`(배당재투자 조정종가)를 총수익 시계열로, `close`를 NAV 침식 추적용으로 씁니다.

> 주의: `range=max` 를 쓰면 야후가 장기 종목을 조용히 월봉으로 다운샘플링합니다(QQQ 기준 6,896개 → 330개). MDD와 1년 수익률이 크게 왜곡되므로 `period1`/`period2` 를 명시해 일봉을 강제합니다.

**한국** — 네이버 금융 `etfAnalysis`(보수·NAV·순자산·TTM 분배금) + `siseJson`(일별 시세).

> 주의: 네이버 `siseJson` 은 **수정주가**를 반환합니다. 과거 가격이 분배락만큼 소급 하향 조정돼 있어 시계열 자체가 이미 분배금 재투자 총수익입니다.
> 근거: 491620은 2024-10-02에 10,000원으로 상장했는데 시계열 첫값이 6,812원, 마지막값 10,970원 ≈ 현재 NAV 10,984원.
> 따라서 여기에 TTM 분배율을 더하면 분배금을 이중 계상하게 됩니다. 미국·한국 모두 총수익 기준이라 직접 비교 가능합니다.
>
> 다만 국내 ETF는 수정주가만 제공되어 "상장 이후 실제 주가 변화(NAV 침식)"를 직접 관측할 수 없습니다. 상장기준가(10,000원, 일부 5,000원) 대비 현재가로 근사합니다.

## 평가 프레임

절대수익으로 줄을 세우면 안 됩니다. 최근 1년 코스피는 +127%, 나스닥100은 +30% 올랐습니다. 절대수익 랭킹은 "한국 상품이 좋다"가 아니라 "한국 증시가 좋았다"를 측정할 뿐입니다. 그래서 모든 종목을 **자기 기초지수**와 짝지어 비교합니다.

- **초과수익(excess)** = 종목 총수익 − 원지수 총수익
- **상승참여율(capture)** = 종목 총수익 ÷ 원지수 총수익. 80%면 상승의 20%를 옵션 매도로 팔아넘긴 것
- **낙폭 방어폭(mdd edge)** = 종목 MDD − 원지수 MDD. 양수면 덜 빠진 것

**종합점수** = 초과수익(40%) + 총수익률(15%) + 낙폭 방어폭(20%) + 분배율(15%) + 저보수(10%)의 백분위 가중합.

`bm_fit: "proxy"` 로 표시된 종목은 기초지수가 벤치마크와 완전히 일치하지 않는 근사 비교입니다(예: AI밸류체인 vs 나스닥100). 상승참여율이 120%를 넘으면 대개 전략의 실력이 아니라 지수 차이 때문입니다.

## 정기 자동 갱신 (GitHub Pages)

대시보드는 GitHub Actions 가 **매주 토요일 오전 8시(KST)** 에 자동으로 다시 빌드해 Pages 로 배포합니다.

- 공개 주소: `https://jinhae8971.github.io/covered-call-lab/`
- 워크플로우: `.github/workflows/update-dashboard.yml` (cron `0 23 * * 5` = 금 23:00 UTC = 토 08:00 KST)
- 수동 실행: Actions 탭 → *Run workflow* (범위를 `all`/`us`/`kr` 중에서 선택 가능)

최초 1회만 아래를 실행하면 레포 생성·push·Pages 활성화·첫 배포가 한 번에 끝납니다.

```powershell
cd C:\Users\spytl\투자\covered-call-lab
powershell -ExecutionPolicy Bypass -File .\setup_github.ps1
```

토큰은 실행 중에만 입력받아 메모리에 두고, push 직후 원격 URL에서 제거합니다. 파일에 기록하지 않습니다.

### 신뢰성 장치

- **품질 게이트** — 49종 중 성공률이 70% 미만이면 갱신을 중단하고 직전 스냅샷을 복원합니다. 야후·네이버가 일시적으로 막혔을 때 정상 데이터가 빈 데이터로 덮이는 사고를 막습니다.
- **push 재시도** — rebase 후 최대 3회 재시도합니다.
- **동시 실행 직렬화** — `concurrency` 그룹으로 스케줄과 수동 실행이 겹쳐도 충돌하지 않습니다.
- **배포물 분리** — `_site/` 에 `index.html` + `data/metrics.json` 만 담아 올립니다. 수십 MB짜리 원시 캐시는 커밋도 배포도 하지 않습니다.

> 네이버 금융이 해외 IP(GitHub 러너)를 차단하면 국내 26종이 실패하고 품질 게이트가 작동해 갱신이 중단됩니다. 그때는 로컬에서 `python build.py` 후 커밋하면 됩니다.
